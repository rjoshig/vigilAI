What happens next
  1. Files are hashed and stored; the run is queued.
  2. Worker runs stages 1–9 (parse → extract → describe → trace → compare → reverse pass → report checks → verify → summarize).
  3. Run moves to Needs review.
  4. You mark each finding OK / Not OK, then generate the frozen report.

Typical duration: 3–6 min. LLM calls: ~2–3 per requirement plus one per config block; cached content is never re-sent.

Privacy
Sample rows and PII never go into a prompt or a log. The model sees requirement text, config blocks, and report cell values only. Masked columns are configured in the admin-ui.
